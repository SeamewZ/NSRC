# Time-MoE detailed evaluation

These files retain the detailed Time-MoE comparator outputs used during the final benchmark audit:

- <code>metrics_by_horizon.csv</code>: all-origin and event-origin errors by cohort, asset, and horizon group;
- <code>horizon_stability.csv</code>: per-horizon errors;
- <code>paired_bootstrap_vs_baselines.csv</code>: paired calendar-block comparisons against the listed reference methods.

This companion analysis is separate from the paper’s primary significance table. The primary NSRC-versus-DLinear bootstrap and Holm-adjusted results are in <code>results/stability/significance.csv</code>.

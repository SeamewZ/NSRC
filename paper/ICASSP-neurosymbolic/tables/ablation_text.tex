Relative to uniform relevance, semantic weighting improves all three errors for Celebrity and Macro equities, but not for News or Macro crypto; the utility of event addresses therefore depends on the cohort. The main router does not select this semantic path in the reported test intervals, so rows 2--13 compare memory mechanisms under a fixed unrouted path rather than explain deployed gains. Removing category has no effect for Celebrity/News because each has one test-time category.

Online updates and volatility scaling matter most in News, where newly matured residuals and current volatility help track a changing event mix. Delayed-feedback calibration helps News and Macro crypto; recency weighting helps Celebrity, News, and equities; cross-asset sharing is most useful in News and Macro crypto. Support shrinkage improves the semantic branch in all cohorts by limiting weakly supported reads. These differing effects explain why a single fixed transfer policy is inadequate. The fallback was inactive, so its benefit is not measured here. Shuffled keys show no uniform degradation, consistent with cohort-dependent value from event addressing.
